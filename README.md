# IMDb Top 250 Scraper

A small Python script that opens IMDb's [Top 250 Movies chart](https://www.imdb.com/chart/top/) in Chrome using Selenium and saves the rank, title and rating of every movie to a CSV file.

## Project structure

```
imdb_scraper/
├── imdb.py             # The scraper script
├── imdb_top_250.csv    # Output (regenerated each successful run)
└── README.md
```

## Requirements

- Python 3.9+
- Google Chrome installed
- Python packages:
  - `selenium`
  - `webdriver-manager`
  - `pandas`

Install the dependencies:

```bash
pip install selenium webdriver-manager pandas
```

`webdriver-manager` downloads a ChromeDriver that matches your Chrome version automatically, so no manual driver setup is needed (internet access is required on the first run).

## Usage

```bash
python imdb.py
```

What happens:

1. Chrome opens and loads the IMDb Top 250 page.
2. The script waits about 20 seconds for the page to render.
3. If IMDb shows a "human verification" page, the script pauses. Complete the check in the Chrome window, then press **Enter** in the terminal.
4. It waits up to 60 seconds for all 250 movie rows to appear.
5. It extracts the rank, title and rating of each row and writes `imdb_top_250.csv` in the current directory.
6. The browser is closed automatically, even if an error occurs.

## Output

`imdb_top_250.csv` has 250 rows and three columns:

| Column | Description                          |
| ------ | ------------------------------------ |
| Rank   | Position in the chart (1–250)        |
| Title  | Movie title                          |
| Rating | IMDb user rating (e.g. `9.3`)        |

Sample:

```csv
Rank,Title,Rating
1,The Shawshank Redemption,9.3
2,The Godfather,9.2
3,The Dark Knight,9.1
```

## Error handling

The script checks its results before writing anything. It raises an error and leaves any existing CSV untouched if:

- a row has no title,
- a row has no rating, or
- the number of movies collected is not exactly 250.

## Notes and limitations

- **Selectors may break.** The script relies on IMDb's current CSS classes (`li.ipc-metadata-list-summary-item`, `ipc-rating-star--rating`). If IMDb changes its page layout, update these selectors in `imdb.py`.
- **Bot checks.** IMDb may show a verification page. The script runs a visible (non-headless) browser so you can solve it manually.
- **Titles.** Titles are read from the page as displayed. Depending on your locale, they may be shown in a translated form.
- **Fixed wait.** The initial 20-second `time.sleep` is deliberately generous; on a fast connection you can reduce it.
- **Terms of use.** Review IMDb's terms of service and robots policy before scraping, and use the data for personal or educational purposes only. IMDb also offers official datasets at <https://developer.imdb.com/non-commercial-datasets/>.
- The `__pycache__/` folder is generated by Python and can be ignored or deleted.
